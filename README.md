# 币安量化回测与自动交易系统

基于 Flask 的币安量化系统，覆盖**策略回测**、**模拟现货**、**自动现货**、**自动合约**、**虚拟币/美股综合量化**、**最优策略汇总**与**邮件通知**等模块，支持多任务并行运行与崩溃恢复。

![系统截图](./iShot_2025-08-19_21.44.41.png)

---

## 一、功能总览

| 页面 | 地址 | 功能 |
|------|------|------|
| 交易回测系统 | `/` | 多策略组合回测（6 种策略可勾选叠加，AND/OR 合成）、止盈止损、收益曲线、交易明细导出 |
| 模拟现货交易 | `/demo` | DemoTrader 模拟下单，绑定 API 密钥 |
| 自动现货交易 | `/auto` | 标准多策略(OR) / 网格交易两种模式，后台线程轮询下单 |
| 自动合约交易 | `/futures` | USDT 永续、做多/做空双向、杠杆、断线保护止损、心跳告警、多任务恢复 |
| 美股综合量化 | `/composite` | 93 只美股代币（NVDA/QQQ/TQQQ 等，按 GICS 板块筛选）组建多股任务 |
| 虚拟币综合量化 | `/crypto-composite` | 市值前 30 主流币（BTC/ETH/SOL...）组建多币任务，一键「全部主流币」 |
| 最优策略汇总 | `/strategies` | 历次寻优回测筛选出的最优策略集中展示（含三年总夏普等详细指标） |
| 个人设置 | `/settings` | QQ 邮箱绑定、修改密码、定时持仓报告开关与发送时间 |

### 回测支持的技术指标

- **RSI**：相对强弱指数（超买超卖）
- **KDJ**：随机指标（金叉死叉）
- **布林带**：价格波动通道
- **EMA**：指数移动平均线（趋势）
- **MACD**：移动平均收敛发散
- **双均线交叉**：SMA 金叉/死叉
- **MACD+背离组合策略族**（综合量化主用）：`macd+背离` / `macd+背离+量能` / `macd+背离+均线+量能`
- 展示指标：SMA、随机指标、ATR（仅绘图，不参与交易）

### 综合量化特色（虚拟币 / 美股）

- **一任务多币对**：每币对独立配置策略、周期、资金权重、做多/做空方向与止盈止损；「统一策略」一键应用到全部币对
- **量化优先匹配**：总资金均分 n 份份额，先触发信号的币先得，平仓后份额回收（先到先得模拟，适合快策略少份额）
- **复利池**：每币对盈亏滚入独立复利池，任务重启后从磁盘恢复累积状态，复利不重置
- **双向交易**：每币对可开启做空（卖出信号平多开空）；空单持仓识别已按单向持仓模式归一化处理
- **任务级隔离**：多个综合任务完全独立（币对、策略、资金互不干扰），支持启停/继续运行/删除/导出配置与全量日志，日志区支持一键清屏（不影响导出）
- **资金安全**：买入按 95% 安全系数下单；绑定 APIKEY 后任务总资金不得超过账户余额（前端上限 + 后端校验）
- **美股板块**：美股代币标记 GICS 板块并支持按板块筛选，含纳指/道指成分股与热门杠杆 ETF（SOXL/NVDL/TSLL 等）

### 合约交易特色

- **双向交易**：买入信号开多，卖出信号平多并开空
- **断线保护止损**：开仓同时在交易所挂 STOP_MARKET 只减仓保护单，服务宕机/断网时由交易所自动止损兜底；信号平仓自动撤单；保护单缺失自动补挂
- **心跳告警**：轮询连续失败 ≥3 次触发告警（页面红框 + 日志 + `data/futures_alerts.log`）
- **成交通知邮件**：每次开多/开空/平仓即时发送 HTML 样式邮件（做多绿/做空红、盈亏着色、开仓均价/杠杆一目了然）
- **任务列表恢复**：每次启动自动记录任务配置，服务崩溃重启后可一键「继续运行」，引擎自动读取交易所真实持仓续跑
- **测试网/主网切换**：默认合约测试网（模拟资金）；TQQQ/QQQ 等美股永续仅主网有
- **默认杠杆 1**：合约与综合量化默认杠杆均为 1，降低默认风险

### 邮件通知（QQ 邮箱）

- `/settings` 绑定 QQ 邮箱与 SMTP 授权码（Fernet 加密入库），可发测试邮件验证
- **定时持仓报告**：每天在设定时间（默认 18:30，可自定义）把**此时此刻的账户真实持仓**（币种、方向、数量、开仓均价、标记价、未实现盈亏、收益率、强平价、USDT 权益）通过邮件推送；数据来自运行中任务绑定的交易所账户，空仓/无任务也会发
- **引擎告警**：无法访问币安时每 10 分钟提醒一封、共 3 封，网络恢复自动重置
- 授权码获取：QQ 邮箱网页版 → 设置 → 账户 → 开启 SMTP 服务

### 最优策略页数据

- **虚拟币**：市值前 20 合约币 × 三种 MACD 组合策略 × 1h/15m × 仅做多/双向 × 不设/止损5%/止盈止损5% 共 36 组配置，2024/2025/2026 分年度收益 + 三年合计盈亏/总夏普/最大回撤/爆仓数；另有市值 21-40 新币回测
- **美股**：92 只美股代币 × 3 种 MACD 变体（Yahoo 1h K线）回测结果
- 支持置顶排序、搜索、类别筛选、逐年收益与交易流水详情

## 二、部署流程

### 1. 环境要求

- Python 3.10+
- Windows / macOS / Linux
- 可访问币安的网络环境（国内需代理，默认代理端口 `7892`）

### 2. 获取代码并创建虚拟环境

```bash
cd Binance_Quantitative_System-main

# 创建并激活虚拟环境
python -m venv venv

# Windows (PowerShell)
.\venv\Scripts\Activate.ps1
# macOS / Linux
source venv/bin/activate
```

### 3. 安装依赖

```bash
pip install -r requirements.txt
```

主要依赖：Flask、ccxt、pandas、numpy、plotly、ta、openpyxl。

> ⚠️ **ccxt 版本必须锁定 4.1.77**：币安已废弃 USDT-M 合约测试网，新版 ccxt 移除了 `binanceusdm` 的 sandbox 支持（保存密钥时报 `NotSupported: testnet/sandbox mode is not supported` 或 `-2008 Invalid Api-Key ID`）。务必使用 `pip install -r requirements.txt` 安装，不要单独升级 ccxt。

### 4. 配置代理（可选）

代理地址在项目根目录的 **`.env`** 文件中配置（默认 `http://127.0.0.1:7892`）：

```bash
HTTP_PROXY=http://127.0.0.1:7892
HTTPS_PROXY=http://127.0.0.1:7892
```

修改后重启服务生效。优先级：**系统环境变量 > .env 文件 > 不设代理（直连）**。也可用环境变量临时覆盖：

```bash
# Windows (PowerShell)
$env:HTTP_PROXY = "http://127.0.0.1:你的端口"
$env:HTTPS_PROXY = "http://127.0.0.1:你的端口"

# macOS / Linux
export HTTP_PROXY=http://127.0.0.1:你的端口
export HTTPS_PROXY=http://127.0.0.1:你的端口
```

不需要代理的环境（如海外服务器）：把 `.env` 中两行的值删除、或将该文件中这两行注释掉即可直连。`.env` 不入库，各机器本地维护。

### 5. API 密钥

- **所有交易页面均需手动填写 API 密钥**（密钥只保存在服务会话内存中，不落盘、不入库）
- 测试网密钥申请：https://testnet.binancefuture.com （登录后 API Key 标签页生成）
- 现货/合约实盘密钥：币安官网账户中心申请，合约交易需开通合约权限

## 三、运行流程

### 1. 启动服务

方式一（推荐，自动检查依赖）：

```bash
python run.py
```

方式二（直接用 Flask）：

```bash
python -m flask run --port 8502 --host 127.0.0.1 --debug
```

### 2. 访问系统

浏览器打开 http://127.0.0.1:8502

**首次访问需初始化登录账号**：系统会显示「初始化管理员账号」页面，设置用户名（4~20 字符）和密码（至少 8 位）。密码使用 scrypt 加盐哈希存入 `data/users.db`，数据库不保存明文；连续输错 5 次锁定 10 分钟。之后所有页面均需登录，导航栏右侧可退出。

- **回测**：首页配置交易对、时间范围、周期、策略与参数、止盈止损 → 运行回测 → 查看收益曲线/指标/交易明细，可下载交易记录
- **综合量化**：`/crypto-composite`（虚拟币）或 `/composite`（美股）→ 添加币对/个股（或点「全部主流币」）→ 配置策略/周期/方向/止盈止损 → 可选开启优先匹配份额 → 设总资金、杠杆 → 启动 → 右侧实时监控各币对信号/持仓/未实现盈亏
- **自动合约**：`/futures` → 选择交易对/周期/策略、开仓金额、杠杆、断线保护止损 % → 启动 → 实时状态区监控持仓/心跳/告警

### 3. 停止服务

终端按 `Ctrl+C`。

### 4. 崩溃恢复

1. 服务意外停止后，交易所侧的止损保护单仍有效，持仓有兜底
2. 重新启动服务，打开对应交易页面
3. 在「量化任务列表」中找到崩溃前的任务，点击「继续运行」
4. 引擎自动读取交易所真实持仓续跑（复利本金/份额等累积状态一并恢复）；若持仓存在但保护单缺失会自动补挂

## 四、项目结构

```
Binance_Quantitative_System-main/
├── app.py                   # Flask 主应用（路由、页面、任务恢复、持仓报告数据源）
├── run.py                   # 启动脚本
├── data_fetcher.py          # 币安行情数据获取（现货/合约，含K线缓存）
├── indicators.py            # 技术指标计算
├── divergence_signals.py    # MACD+背离组合策略信号（背离/量能/均线共振）
├── backtest_engine.py       # 回测引擎（多策略 AND/OR、止盈止损）
├── chart_utils.py           # Plotly 图表工具
├── demo_trader.py           # 模拟现货交易
├── auto_trader.py           # 自动现货交易引擎
├── futures_trader.py        # 合约交易连接器（止损保护单、空单归一化、封禁退避）
├── auto_futures.py          # 自动合约交易引擎（双向/保护单/告警/任务）
├── composite_trader.py      # 综合量化引擎（虚拟币/美股通用：多币对/复利池/优先匹配）
├── daily_signal_report.py   # 定时持仓报告邮件（调度器+HTML模板）
├── mailer.py                # QQ 邮箱发送（纯文本/HTML）
├── auth.py                  # 登录认证与邮箱配置
├── changelog.py             # 版本历史
├── templates/               # 页面模板（index/demo/auto/futures/composite/strategies/settings）
├── static/                  # 样式与静态资源
├── scripts/                 # 寻优与回测脚本（results/ 下为回测 summary，随仓库分发）
├── data/                    # 运行状态与任务记录 JSON（均不入库）
└── requirements.txt         # Python 依赖
```

> 密钥安全：API 密钥仅存于登录会话内存，QQ 邮箱授权码 Fernet 加密存于本地 `data/users.db`；`users.db`、`.env`、任务状态文件均已通过 `.gitignore` 排除，不会随仓库分发。

## 五、常见问题

| 问题 | 解决方法 |
|------|---------|
| 页面打不开 | 确认服务已启动、端口 8502 未被占用；浏览器 Ctrl+F5 强制刷新 |
| 拉取行情失败/超时 | 检查代理是否开启、端口是否为 7892；网络波动会自动重试 |
| 429 Too Many Requests | 币安接口限流（多为共享代理 IP 触发）；系统内置K线缓存与退避，偶发可忽略，频发换代理节点或直连 |
| -1003 IP 封禁 | 请求过密被币安临时封禁；引擎会按 `banned until` 自动等待到期，请勿频繁重启 |
| 合约下单报 Invalid API-key | 测试网用测试网密钥；主网用实盘密钥并确认已开合约权限 |
| 测试网选 TQQQ/QQQ 报错 | 美股永续仅主网有，把「网络」切换为主网（真实资金，注意风险） |
| 开美股合约报 -4411 | 系统会自动签署 TradFi-Perps 协议并重试，无需手动处理 |
| 改了杠杆不生效 | 在「交易配置」卡片修改杠杆后点「启动自动交易」即生效（综合量化默认 1x） |
| 综合任务总资金保存失败 | 绑定 APIKEY 后总资金不得超过账户可用余额，按提示调低 |
| 定时持仓报告没收到 | `/settings` 确认已开启并绑定 QQ 邮箱；当天已发过不会重复（可点「立即发送一次」测试） |
